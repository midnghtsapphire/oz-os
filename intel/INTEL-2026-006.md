# Gate irreversible inference on a computed coverage test, not on judgement

## What we learned

When a system is asked to produce output in a region where its input carries no
information, the durable fix is a **computed gate evaluated before the output
exists** — not a policy, a prompt instruction, or a reviewer's judgement.

The occlusion-forensics pack made this concrete. Reconstructing content behind a
mask is not a hard problem but an ill-posed one: a masking operator is a
projection with a non-trivial null space, so the data constrains nothing about
the hidden component and infinitely many scenes fit the measurement equally
well. Compressed sensing does not rescue it, because a contiguous occluder is
coherent structured loss and violates the restricted isometry property the
guarantees require.

The generalisable part is the *shape of the fix*. `coverage.py` counts, per
pixel, how many registered frames actually observed each location. `recovery.py`
writes `NaN` wherever that count is zero, with no parameter to override. The
decision is made from observation geometry alone, **before** any reconstruction
exists to be admired — which is what stops it being rationalised afterwards by
how good the output looks.

Two corroborating findings from the same cycle:

- **Verdict labels must be outputs, never inputs.** The commissioning prompt
  hardcoded `Race/ethnicity → DETERMINATE` and similar. Fixing a label
  independent of evidence guarantees a positive assertion regardless of support.
  The countermeasure is a `Determination` enum whose `MEASURED` case cannot be
  constructed without a region, a value *and* an uncertainty.
- **Current multimodal search agents retrieve; none reconstruct.**
  DeepMMSearch-R1 (arXiv:2510.12801) crops a query-relevant subregion and
  searches it, with no pixel-synthesis path at all. Proposals that chain "search"
  to "reconstruct identity" are assuming a capability that does not exist in the
  cited work.

## Why it matters

Oz OS agents routinely face the same structural situation: asked for a
conclusion where the evidence does not reach. `NULL_RESULT_SCHEMA.md` already
establishes that "found nothing" is a valid output, but it relies on the agent
*choosing* honesty at write-up time. This intel supplies the stronger pattern —
make the null case unrepresentable in the data structures, so the honest output
is the only constructible one.

This is the same lever as `wr-lint` and the Tier system: move enforcement out of
reviewer attention and into something that runs.

## How to apply it

1. When designing any agent that emits confident output over partial evidence,
   add an explicit coverage-style precondition that is computed and logged
   separately from the output, and make the refusal path structural rather than
   advisory.
2. Extend `agents/verifier.md` to check that packs claiming a measurement cite
   the region and error bound, mirroring the `Claim` contract.
3. Adopt the "labels are outputs" rule in agent specs: no agent spec should
   enumerate the verdict it expects to reach.
4. Reuse `research-packs/occlusion-forensics/reference-impl/` directly for any
   image-provenance work; the enhancement-chain detector in particular
   (`methods/04-rejected-and-provenance.md`) generalises to auditing any
   upscaled or "enhanced" media before it is relied upon.

## When it stops being true

The linear-algebra core does not expire. The specific claim about multimodal
search agents lacking a reconstruction path needs re-verification as that
literature moves — re-check at the stated half-life. If a future method
demonstrates recovery guarantees under coherent structured loss (a genuine RIP
relaxation covering contiguous masks, not merely convincing samples), the
"one exception" section of the pack README must be revised. Note that
perceptual-quality improvements are not evidence of this and should not be
mistaken for it.
